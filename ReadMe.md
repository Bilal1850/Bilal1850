# 💫 About Me:

My experience includes working with Cloudera and Microsoft Fabric, along with technologies such as Apache Spark and Airflow. I enjoy exploring how data platforms, big data tools, cloud systems, and agentic AI can work together to turn complex needs into useful solutions. I’m continuing to build and share practical examples of the work I do, while learning and experimenting with new technologies.
